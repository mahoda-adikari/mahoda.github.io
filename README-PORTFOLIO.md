# Mahoda Adikari — QA Engineer Portfolio

A responsive, static portfolio built from the supplied Bootstrap 4 Resume template and populated from Mahoda Adikari's CV.

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in a web browser.

No build step or server is required. The Bootstrap, jQuery and icon assets are included in `vendor/`. Google Fonts are loaded from Google Fonts when online; the site remains usable if they are unavailable.

## Publish free with Netlify (quickest)
1. Extract the ZIP file on your computer.
2. Open https://app.netlify.com/drop
3. Drag the extracted **mahoda-portfolio** folder (the folder containing `index.html`, `css/`, `js/`, `img/` and `vendor/`) onto the page.
4. Netlify will publish it and provide a public `*.netlify.app` URL. Create/sign in to a free account if you want to keep managing the site and redeploy updates.
5. To change the URL, open the site in your Netlify dashboard and edit its site name.

For later updates, edit the files and upload the updated site folder again from the site's Deploys page.

## Alternative: GitHub Pages
1. Create a public GitHub repository named `yourusername.github.io`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Wait for GitHub Pages to publish your site at `https://yourusername.github.io`.

GitHub Pages supports static HTML/CSS/JavaScript sites on GitHub Free public repositories. See https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages.

## Before publishing
- Review the public phone number and email address and decide whether you want both displayed.
- Your residential street address is intentionally not included.
- No LinkedIn, GitHub, or other social profile links were added because none were supplied in the CV. Add your real profile URLs if you want them shown.
- The portfolio does not publish the original CV PDF, to avoid exposing the residential address in that document.
- The project descriptions are limited to information supplied in the CV; add repository/demo links and screenshots when available.
